# Specification Doc Parser  
  
Программа для автоматизированного преобразования спецификаций интерфейсов в формате DOCX в структурированный документ формата Markdown. Результат предназначен для последующего использования во внешних LLM системах, а также для ревью полноты описания.  
  
### Требования  
  
- Операционная система: Windows  
- Python: 3.14 или выше  
- Зависимости из requirements.txt  

### Особенности  
  
- Консольное взаимодействие  
- Поддерживаемый формат входных файлов: Google Doc или DOCX  
- Для корректной работы программы спецификации должны быть написаны в соответствии с "Шаблоном документа для описания функциональности"  
- Распознавание основано на заданных правилах и текстовых шаблонах. Не все нестандартные формулировки могут быть корректно распознаны.  
- Для выгрузки из Google Docs требуется настройка проекта в Google Cloud Console.
  
### Использование  
  
1. Пользователь выбирает способ загрузки документа:
	1. Google Docs
	2. Локальный DOCX
2. Пользователь указывает ссылку на Google документ или путь к DOCX-файлу
3. В случае с выгрузкой Google Docs пользователь проходит авторизацию в свой Google аккаунт.
4. Программа запрашивает путь к DOCX файлу.  
5. Пользователь передает путь в программу.  
6. Программа поэтапно обрабатывает документ.  
7. Сформированный Markdown файл сохраняется в result/interface_spec.md.  
  
#### Этапы обработки  
  
1. Получение документа из Google Docs
2. Чтение DOCX-документа
3. Извлечение структуры документа и иерархии разделов  
4. Распознавание элементов интерфейса и их свойств  
    - Значения локальных справочников: имя, описание
    - Колонки таблиц: имя, тип данных, описание
    - Контролы: имя, тип, обязательность, значение по умолчанию, описание
5. Преобразование информации в Markdown формат  
6. Формирование оглавления  
7. Экспорт данных в файл формата .md  

#### Настройка Google Docs API
Для выгрузки из Google Docs перед запуском необходимо настроить проект в Google Cloud Console.

1. Создать Google Cloud Project
2. Включить Google Drive API
3. Настроить OAuth Consent Screen
4. Создать OAuth Client ID с типом Desktop app
5. Скачать файл credentials.json
6. Поместить в DocParser/integrations/
  
### Структура проекта  
  
```  
DocParser  
|── config/  
|    |── control_types.py           # Словарь компонентов интерфейса  
|    └── document_config.py         # Настройки для шапки .md документа  
|── data/
|    └── google_docs/               # Выгруженные из Google Drive документы
|    └── tests/                     # Примеры DOCX документов для обработки  
|── exporters/  
|    |── md_exporter.py             # Экспорт данных в Markdown файл  
|    └── md_structure_builder.py    # Преобразование данных в Markdown формат
|── integrations/
|    |── google_auth.py             # Авторизация в аккаунте Google 
|    |── google_docs_downloader.py  # Выгрузка DOCX из Goggle Docs
|    |── credentials.json           # Данные OAuth-клиента приложения
|    └── token.json                 # Токены авторизации пользователя
|── logs/  
|    |── logger.py                  # Логирование  
|    └── doc_parser.log             # Файл для логов  
|── parsers/  
|    |── docx_parser.py             # Чтение исходного DOCX файла  
|    |── semantic_parser.py         # Извлечение семантических разделов  
|    └── structure_parser.py        # Восстановление структуры документа  
|── result/                         # Директория с итоговым Markdown файлом    
|── document_processor.py           # Запуск всех этапов обработки  
|── main.py                         # Взаимодействие с пользователем  
|── README.md                       # Основная информация о проекте  
└── requirements.txt                # Зависимости  
```
