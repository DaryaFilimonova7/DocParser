# Specification Doc Parser

Программа для автоматизированного преобразования спецификаций интерфейсов в формате DOCX в структурированный документ формата Markdown. Результат предназначен для последующего использования во внешних LLM системах, а также для ревью полноты описания.

### Требования

- Операционная система: Windows
- Python: 3.14 или выше
- Зависимости из requirements.txt

### Особенности

- Консольное взаимодействие
- Поддерживаемый формат входных файлов: DOCX
- Для корректной работы программы спецификации должны быть написаны в соответствии с "Шаблоном документа для описания функциональности"
- Распознавание основано на заданных правилах и текстовых шаблонах. Не все нестандартные формулировки могут быть корректно распознаны.

### Использование

1. Пользователь выгружает спецификацию Google Doc в DOCX формат.
2. Пользователь запускает программу.
3. Программа запрашивает путь к DOCX файлу.
4. Пользователь передает путь в программу.
5. Программа поэтапно обрабатывает документ.
6. Сформированный Markdown файл сохраняется в result/interface_spec.md.

#### Этапы обработки

1. Чтение документа формата .docx
2. Извлечение структуры документа и иерархии разделов
3. Распознавание элементов интерфейса и их свойств
	- Локальные справочники
	- Колонки таблиц
	- Контролы
4. Преобразование информации в Markdown формат
5. Формирование оглавления
6. Экспорт данных в файл формата .md

### Структура проекта

```
DocParser
|── config/
|    |── control_types.py         # Словарь компонентов интерфейса
|    └── document_config.py       # Настройки для шапки .md документа
|── data/
|    └── tests/                   # Примеры DOCX документов для обработки
|── exporters/
|    |── md_exporter.py           # Экспорт данных в Markdown файл
|    └── md_structure_builder.py  # Преобразование данных в Markdown формат
|── logs/
|    |── logger.py                # Логирование
|    └── doc_parser.log           # Файл для логов
|── parsers/
|    |── docx_parser.py           # Чтение исходного DOCX файла
|    |── semantic_parser.py       # Извлечение семантических разделов
|    └── structure_parser.py      # Восстановление структуры документа
|── result/                       # Директория с итоговым Markdown файлом
|
|── document_processor.py         # Запуск всех этапов обработки
|── main.py                       # Взаимодействие с пользователем
|── README.md                     # Основная информация о проекте
└── requirements.txt              # Зависимости
```
